# 給 Codex 的指令

請讀取 `docs/CODEX_FRONTEND_PLAN.md` 並依序執行前端工作。規格以 `docs/CODEX_FRONTEND_HANDOFF.md` 為準，backend 欄位以 `docs/BACKEND_SNAPSHOT_EVENTS.md` 為準，美術沿用 `docs/ART_DIRECTION.md` 的 Soft Pixel 魚蝦風格。先把目前還沒 commit 的前端收好，只 commit 自己的檔案。蝦精緻化做完素材和比較圖後要先停下來給使用者看，使用者說好才整合。不要在本機跑長時間模擬。每項結果都要標明已完成、未完成或需要 backend，不要只寫「完成」。
